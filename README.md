# Оно тебе надо

Проектная работа Яндекс Практикума: лендинг аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/HardStormer/ono-tebe-nado-ad

## Технологии

- семантическая HTML-разметка;
- БЭМ-именование классов;
- раскладка на Flexbox и Grid;
- подключение шрифтов через `@font-face`.
